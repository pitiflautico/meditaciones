## 🎧 Especificaciones Técnicas Generales

### Audio Master
- **Formato**: WAV 48 kHz / 24 bit
- **LUFS**: -17 a -18 dB
- **True Peak**: Máximo -1.0 dB

### Procesamiento de Voz
- **Nivel**: -6 dB (picos)
- **EQ**: Corte pasa-altos 75-80 Hz, realce 3-4 kHz
- **Compresión**: Ratio 3:1
- **Reverb**: 8-18% según la fase
- **De-esser**: 6-8 kHz

### Música y Ambientes
- **Nivel base**: -20 a -24 dB
- **Frecuencias binaurales**: 4-7 Hz (Theta) principalmente
- **BPM**: 40-60 (adecuado para meditación)
- **Instrumentación**: Cuencos tibetanos/cristal, sintetizadores ambient, elementos naturales
